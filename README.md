# Drone Course

Учебная сцена для задания «Дрон сквозь рамки» (Unity 6, Input System).

## Запуск

После открытия проекта и завершения импорта выберите меню `Simulation Course > Build Drone Course Scene`. Оно создаст `Assets/Scenes/DroneCourse.unity` и добавит сцену в Build Settings. Затем откройте её и нажмите Play. На сцене есть дрон с одним `Rigidbody`, пять рамок на высотах 2.5–3.6 м, физические перекладины, порядок прохождения, таймер и HUD. Следующая рамка подсвечивается янтарным цветом, пройденная — бирюзовым.

## Управление

- `W` / `S` — наклон по тангажу; наклон создаёт горизонтальную тягу.
- `A` / `D` — крен.
- `Q` / `E` — рыскание.
- `Space` — набор высоты.
- `Left Ctrl` (или `C`) — снижение.
- `R` — вернуть дрон на старт.

Дрон автоматически удерживает высоту без ввода. При наклоне вертикальная составляющая тяги уменьшается; стабилизатор возвращает корпус к горизонту и не гасит рыскание.

## Структура

- `DroneLift` — тяга вдоль локальной оси вверх и помощь удержания высоты.
- `DroneManualAttitude` — ручные моменты по трём осям.
- `DroneAutoLevel` — PD-стабилизатор на ошибке ориентации и угловой скорости.
- `Gate` / `GateCourse` — засчитывание только чистого пролёта нужной рамки вперёд.
- `DroneCourseSceneBuilder` — редакторское меню `Simulation Course > Build Drone Course Scene` для пересборки сцены.

Ворота засчитываются только при входе основного `Rigidbody` в триггер по направлению локальной оси `+Z`, в заданном порядке. Коллайдеры перекладин остаются твёрдыми.
